# ZI Office

Мобильное приложение для чтения и работы с документами: PDF, Word, Excel,
PowerPoint, RTF, текстовые файлы. Android, minSdk 24.

## Возможности

- Чтение PDF (нативный рендер с масштабированием, прокруткой и переходом
  к странице), Word, Excel, PPTX, RTF, TXT
- Поиск по документу, закладки, тёмная тема
- Озвучка текста (TTS), режим чтения
- Распознавание текста в PDF (OCR, русский язык, Tesseract)
- Инструменты PDF: поворот, извлечение/удаление страниц, пустая страница,
  обратный порядок, нумерация страниц
- Сканер: фото страниц → PDF
- Объединение нескольких PDF в один
- Облака: Google Drive и Яндекс Диск (папка через SAF + встроенный браузер)
- Сохранение/отправка/печать, сохранение в облако
- Эластичная прокрутка: документы и списки тянутся за край и возвращаются
  пружиной (как в iOS), внутри границ — обычная инерция
- Экран «О программе»: версия и номер сборки, кнопка проверки/установки
  обновления, контакты и раскрывающиеся частые вопросы (кнопка в главном окне,
  пункт меню «⋮» или долгое нажатие на заголовок)
- Открытие файлов из других приложений: «Открыть с помощью» (ACTION_VIEW)
  и «Поделиться» (ACTION_SEND), включая ссылки `file://` и список файлов
- Отчёт об ошибке: после сбоя приложение при следующем запуске предлагает
  отправить разработчику текст ошибки (версия, модель, стек)
- Автообновление: приложение само раз в 6 часов (даже закрытым) проверяет
  новые версии, скачивает APK и показывает уведомление — установка в одно
  нажатие; переключатель «Обновляться автоматически» на экране «О программе»

## Сборка APK

### Автоматически (GitHub Actions) — рекомендуемый способ

Ничего собирать на компьютере не нужно.

- **Готовая сборка на каждый коммит** — workflow «Сборка APK»
  (`.github/workflows/build.yml`): запускается на пуши в `main` и в ветки
  `arena/*`, на пул-реквесты и вручную.
  Скачать APK: вкладка **Actions** → нужный запуск → внизу **Artifacts** →
  `ZIOffice-<версия>-<commit>.zip`.
- **Релиз (то, что видят пользователи)** — workflow «Релиз APK»
  (`.github/workflows/release.yml`): запускается по тегу `v*` или вручную.

```bash
git tag v2.24 && git push origin v2.24     # выпустить версию 2.24
```

Подробности и одноразовая настройка публичного репозитория обновлений —
в [АВТООБНОВЛЕНИЕ.md](АВТООБНОВЛЕНИЕ.md).

### На своём компьютере

Требуется JDK 17 и Android SDK (platform 34, build-tools 34).

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Или открыть проект в Android Studio и собрать.

## Версия приложения

Номер версии задаётся **только** в `app/build.gradle`:

```gradle
versionName "2.23"      # versionCode считается из него: 2.23 -> 20300
```

`versionCode` вычисляется из `versionName` (2.24 → 20400, 2.24.1 → 20401),
поэтому сборку с «отставшим» номером выпустить нельзя — Android такие
обновления отклоняет.

Версию можно переопределить без правки файла — так делает CI:

```bash
./gradlew assembleRelease -PversionName=2.24
```

## Подпись

Ключ выпуска: `signing/myoffice-release.p12` (единственная копия в проекте),
пароль и alias — в `signing/ПОДПИСЬ.txt` и в `app/build.gradle`.

> ⚠️ Без этого ключа нельзя выпускать обновления того же приложения.
> Храните его в надёжном месте. Репозиторий приватный — не делайте его
> публичным, не удалив сначала ключ из истории.

## Автообновление

Приложение само проверяет наличие новой версии (раз в 6 часов) и предлагает
скачать APK. Сборка и публикация релизов — GitHub Actions по тегу `v*`.

Проверить вручную: в главном окне меню «⋮» → «Проверить обновления» —
приложение скажет, что происходит («установлена последняя версия»,
«репозиторий обновлений не найден» и т. п.).

**Подробная инструкция (включая одноразовую настройку): [АВТООБНОВЛЕНИЕ.md](АВТООБНОВЛЕНИЕ.md)**

Коротко:
1. Публичный репозиторий `zigorminsk-debug/ZI-Office-Release` + secret
   `RELEASE_TOKEN` (разово). Имя репозитория можно поменять переменной
   репозитория `RELEASE_REPO` и параметром сборки `-PreleaseRepo=...`.
2. `git tag v2.XX && git push origin v2.XX` — всё, релиз опубликован.

## CI

`.github/workflows/`:

- `build.yml` — собирает release-APK на пуши/пул-реквесты, прогоняет тесты,
  выкладывает APK артефактом; при падении создаёт issue с хвостом лога;
- `release.yml` — по тегу `v*` (или вручную) собирает APK нужной версии и
  публикует GitHub Release в публичном репозитории обновлений; если секрет
  `RELEASE_TOKEN` не задан, релиз создаётся в текущем репозитории, а в
  описании запуска печатается, что осталось настроить.

## Структура

```
app/src/main/java/com/docreader/app/
  MainActivity          главное окно (недавние файлы)
  ViewerActivity        просмотрщик (PDF нативно, остальное — WebView)
  PdfZoomView           прокрутка/масштаб PDF, страницы грузятся по мере показа
  ZoomSurface           масштаб и прокрутка для WebView-просмотра
  ElasticPan            эластичная прокрутка (сопротивление за краем + пружина)
  ElasticScrollView     список с «резинкой»
  AboutActivity         «О программе»: версия, обновление, частые вопросы
  CrashGuard            сбор отчёта о сбое и журнала некритичных ошибок
  CrashActivity         просмотр и отправка отчёта об ошибке
  CloudActivity         подключение облаков
  CloudBrowseActivity   файловый менеджер подключённой папки (SAF)
  CloudBrowserActivity  встроенный браузер облака
  ScanActivity          скан в PDF
  MergeActivity         объединение PDF
  OcrHelper             Tesseract, распознавание страниц
  UpdateManager         автообновление: проверка, загрузка, уведомление
  UpdateJobService      периодическая проверка в фоне (JobScheduler)
  ApkInstaller          системный установщик и разрешения на установку
app/src/main/assets/
  viewer.html           рендер Word/Excel/PPT/текста в WebView
  pdftools.html         инструменты PDF (pdf-lib)
  js/                   pdf.js, mammoth, xlsx, jszip, pdf-lib
  tessdata/             модель OCR (rus.traineddata)
signing/                ключ подписи и его описание
```
